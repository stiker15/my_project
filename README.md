# Проект для анализа транзакций

Это приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты,
а также предоставлять другие сервисы.
## Структура проекта

Проект состоит из следующих модулей:

1. main.py
Осуществляет запуск всех модулей проекта

2. views.py
В данном модуле объеденены основные функции для генерации JSON-ответов 

3. utils.py 
Реализован набор функций:
1) get_time_for_greeting Приветствие в формате 
"???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» 
в зависимости от текущего времени.
2) get_card_with_spend По каждой карте:
последние 4 цифры карты;
общая сумма расходов;
кешбэк (1 рубль на каждые 100 рублей).
3) get_top_transaction Топ-5 транзакций по сумме платежа.
4) get_currency Курс валют.
5) get_stock Стоимость акций из S&P500.

4. services.py
analyze_cashback_categories_from_excel функция позволяет проанализировать, какие категории были наиболее выгодными
для выбора в качестве категорий повышенного кешбэка.

5. reports.py
Здесь реализованы отчеты.
Создан декоратор для функций-отчетов, который записывает в файл результат,
который возвращает функция, формирующая отчет.
Декоратор с параметром — принимает имя файла в качестве параметра.

## Проверка кода

В проекте выполнены проверки линкерами:
- Flake8: для проверки стиля кода.
- mypy: для статической типизации.
- black: для автоматического форматирования кода.
- isort: для сортировки импортов.
